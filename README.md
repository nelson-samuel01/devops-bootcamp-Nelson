# My DevOps Bootcamp Journey

Name: Nelson Samuel

Date Started: 9th September, 2026

## Why I Joined This Bootcamp

With over seven years experience across Azure DevOps cloud support, network engineering, and enterprise IT, and Azure certifications including AZ-104, AZ-305, and AZ-400, I joined the Darey.io DevOps Bootcamp to move from supporting and troubleshooting cloud environments to designing and automating them. My goal is to build hands-on depth in Linux, CI/CD pipelines, containerization, and infrastructure as code, so I can help teams ship reliable systems faster instead of just fixing them after the fact. I am motivated by the chance to turn my production-support experience into engineering practice and grow into a DevOps and cloud automation role.

## What I Learned in Session 1

- DevOps is a culture + practices + toolchain
- CALMS framework: Culture, Automation, Lean, Measurement, Sharing
- 8-stage lifecycle: Plan, Code, Build, Test, Release, Deploy, Operate, Monitor
- Local environment is fully configured and ready
